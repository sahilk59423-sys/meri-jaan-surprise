MERI JAAN SURPRISE WEBSITE - READY TO USE

WHAT IS INSIDE
- All 10 photos provided by you
- Your uploaded music converted to a smaller MP3 file
- Animated intro, countdown, slideshow, memory orbit, notes, gallery,
  random-memory shuffle, love question, opening letter, promise heart,
  lightbox, cursor hearts, sparkles and final celebration
- Fully responsive for phone and laptop

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder named Meri_Jaan_Surprise_Website.
3. Double-click index.html.

IMPORTANT
- Keep index.html, style.css, script.js, music.mp3 and the photos folder together.
- On some phones, opening a local HTML file may block music autoplay. Tap the music button once.
- To change the displayed name, open script.js and edit:
  const displayName = "Meri Jaan ❤️";
- The countdown target is 1 August 2026. To change it, edit:
  const targetDate = new Date("2026-08-01T00:00:00");

FOR SHARING AS A LINK
